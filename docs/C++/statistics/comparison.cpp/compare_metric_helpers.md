# Helpers de comparación

Este archivo implementa funciones auxiliares locales para comparación. [`arithmetic_mean`](arithmetic_mean.md) resume una muestra no vacía; [`estimate`](estimate.md) escoge media/mediana; [`bootstrap_difference_interval`](bootstrap_difference_interval.md) remuestrea dos variantes; [`samples_by_pair`](samples_by_pair.md) indexa pair IDs; [`metric_values`](metric_values.md) extrae valores disponibles; [`comparison_seed`](comparison_seed.md) deriva seed estable; [`find_group`](find_group.md) localiza la variante. Son detalles internos, no API pública.
